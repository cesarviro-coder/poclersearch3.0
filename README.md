# PoclerSearch: resultados propios dentro de la página

Esta versión evita redirigir automáticamente a DuckDuckGo. La búsqueda se muestra dentro de PoclerSearch.

## Qué incluye
- **Páginas:** resultados de la API pública de Wikipedia en español.
- **Imágenes:** resultados de Wikimedia Commons.
- **Vídeos:** vídeos disponibles en Wikimedia Commons.
- **Noticias:** resultados del servicio público GDELT.

## Publicar la actualización en GitHub Pages
1. Abre el repositorio `https://github.com/cesarviro-coder/poclersearch`.
2. Pulsa **Add file → Upload files**.
3. Descomprime este ZIP en tu ordenador.
4. Sube los archivos `index.html`, `style.css`, `app.js` y `README.md` desde la carpeta `PoclerSearch-propio`. Si GitHub pregunta si quieres reemplazar los archivos existentes, confirma.
5. Pulsa **Commit changes**.
6. Espera uno o dos minutos y abre `https://cesarviro-coder.github.io/poclersearch/`. Si ves la versión antigua, recarga con `Ctrl + F5`.

## Limitación importante
Esto es una web estática y gratuita. Los resultados se consultan a servicios públicos desde el navegador. No rastrea ni indexa toda Internet como Google o Bing, y no requiere una clave API propia. La disponibilidad depende de los servicios externos.
